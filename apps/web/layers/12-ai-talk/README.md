# layers/12-ai-talk — 访客 AI 对话域

面向访客的简历问答：对话界面、会话状态与访客线索。

## 边界

- **属于本域**：对话输入 / 消息渲染 / 会话切换、访客侧的本轮状态、以及本域的展示组件与类型。
- **不属于本域**：AI 能力的实现与治理（在 `apps/admin` 与后端）、简历展示（`11-public-resume`）。
- **依赖方向**：只依赖 `app/`（底座）与自身。

## 数据

- 对话接口（含流式）走 `~/apis/*`；流式响应的接入方式与 `$request` 的分工在实现该模块时确定并回写 `docs/dev/data-layer.md`。
- 缓存策略由 colada 声明，key 统一在 `~/lib/query-keys`。

## 现状

- 目前只有域入口页 `/ai-talk`（骨架）。
