# 简历 PDF 配置（DAO-048 / #59）

## 已确认目标与边界

每份简历可保存独立纸面配置；每个用户的工作区保存一份公共预设，跨本人简历复制使用。系统默认、公共预设、当前简历配置三者职责明确；公共预设更新不自动改已保存简历。不实现多预设管理、历史发布快照、分享、任意 HTML/CSS、图片或部署。

## 存储与兼容

- `resume_workspaces.pdf_config Json?`：用户自己的公共预设，不是平台所有用户共用。预设剔除模块实例 ID。
- `resume_drafts.document.display.pdf?`：当前简历配置，缺少时按系统默认解析，旧文档不批量改写，schemaVersion 仍为1（可选字段向后兼容）。
- 配置包括模块顺序与显隐（跟随网页/独立）、字段显隐、四边距mm、字号px、行高、模块间距px、主题色、页眉页脚。
- 页眉页脚使用有限变量 `{name}` / `{page}` / `{pages}`，纯文本转义，固定单行高度参与分页；首页可隐藏但仍预留空间以保持版心一致。
- 预设应用仅复制字段/样式/页眉页脚，保留当前模块选择；恢复系统默认是显式操作。

## 接口与并发

- GET/PATCH `/resume/pdf-preset`：读写本人公共预设。
- GET/PATCH `/resume/:id/pdf-config`：读写本人简历配置；写入需 Resume.Display:edit 与所有权。
- PATCH 输入带 `expectedConfig`，比较已保存值（缺省为null），冲突409，不静默重试覆盖。
- 配置写入使用完整旧 JSON 条件更新（CAS）保护读改写；完整正文、网页 display 写入须保留最新 PDF 配置，避免相互覆盖。
- 导出 POST `/resume/:id/pdf` 增加可选严格校验的 `pdfConfig`，先验证原始文档hash，再以本次配置生成；只读页临时配置不改作者数据。

## 用例伪代码

保存简历配置：输入id/config/expectedConfig → 认证 → 检查展示编辑权限 → 事务查询本人简历 → 校验配置引用模块 → 比较配置，再以旧JSON为CAS条件写入 → 失败409 → 返回已保存配置；不改正文revision。

保存公共预设：认证/权限 → 确保本人工作区存在 → 规范化为无实例ID的预设 → CAS条件更新 → 冲突409 → 返回值；不联动简历。

预览与下载：表单本地编辑 → 校验通过后更新预览配置并重新分页 → 下载携带当前配置+源文档hash → 服务端重读可访问文档并比对hash → 校验/渲染配置 → 返回PDF。未保存会明确标识，可以临时下载，不冒充已持久化。

## 交互与验收

共享配置面板：内容、纸张与文字、页眉页脚；桌面侧边栏、手机抽屉。保存当前简历、保存公共预设、应用公共预设、恢复默认分开；只读访客不出现写作者配置按钮。输入非法时禁保存/下载，渲染保留上一份有效配置并明确提示。

测试覆盖旧文档、数值边界、引用与重复ID、他人/无权限、并发409、公共预设隔离、正文/配置并发保留、复制简历、临时导出一致性、长文档/页眉页脚和桌面/手机。数据库验证使用隔离实例，现有库需Owner单独确认。

## 回滚

撤销应用提交恢复旧导出；新增可空列可保留。删除列为单独确认的破坏性动作。无新依赖、环境变量、Docker或发布变更。
