# F01 登录与身份接口

日期：2026-11-03。基线：`dev@9367c32`。以下为当前源码整理的 Markdown 接口说明；示例均为合成数据，未在本轮发送请求。通用包装和全量路由见 [API 总目录](00_接口目录与交付约定.md)，业务语义见 [需求](../01_需求文档/01_登录注册与账号权限.md)。

## 1. POST /api/auth/login

匿名，JSON，成功 HTTP 200。来源：[loginSchema](../../apps/server/src/auth/dto/login.schema.ts)、[AuthService](../../apps/server/src/auth/auth.service.ts)。

| 字段 | 必填 | 当前规则 |
| --- | --- | --- |
| account | 是 | 字符串，去首尾空白后 3～64 字符；含 @ 按邮箱，否则按用户名，小写匹配 |
| password | 是 | 字符串，6～20 字符，不 trim |
| 其他字段 | 不接受 | strictObject 拒绝 username/email/roleKey 等额外字段 |

```json
{
  "account": "learner@example.com",
  "password": "DemoPass123!"
}
```

运行时 schema 实际为密码 6～20 字符；源码注释仍留有旧的 4～64 描述，文档不沿用过时注释。

成功 data 字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| token | string | 访问令牌，真实值不得进入文档 |
| userId | string | 当前用户 cuid |
| email | string 或 null | 当前邮箱 |
| nickname | string 或 null | 当前昵称 |
| roleKeys | string[] | 当前角色集合 |
| permissionKeys | string[] | 当前权限并集，去重排序 |

以下是外层响应形状示意，token 为占位符，不能用于请求：

```json
{
  "code": 200,
  "data": {
    "token": "<access-token>",
    "userId": "demo-user-id",
    "email": "learner@example.com",
    "nickname": "学习者",
    "roleKeys": ["user"],
    "permissionKeys": []
  },
  "message": "ok",
  "timestamp": "2026-11-03T00:00:00.000Z"
}
```

message/timestamp 为说明包装的示意值，客户端不依赖文案判断分支。响应不包含 passwordHash、sessionVersion；token 签名不代表加密，不将隐私资料与权限快照放进载荷。

| HTTP | errorCode | 调用方行为 |
| --- | --- | --- |
| 400 | Common.Validation:failed | 展示输入错误，保留可修正项 |
| 401 | AUTH.Credentials:invalid | 统一凭据错误，不区分账号存在性 |
| 429 | AUTH.Login:throttled | 提示稍后重试，不立即循环发送 |
| 500 | 服务错误出口 | 表达服务故障，不误报成密码错误 |

当前限流内存存储；多实例一致性尚未证明。登录成功会签发 token，不是幂等资源更新；网络失败不可直接推定凭据错误。

## 2. GET /api/auth/info

Bearer 认证，无 body；成功 HTTP 200。全局 Guard 验签、检查账号与会话版本后，返回上表身份字段，但无 token。

恢复链路：读取 Cookie → 请求 info → 更新身份与前端权限；401 清理会话并重新登录，网络/服务异常与会话失效分别处理。角色调整在下一次受保护请求回查时生效。

## 3. 注册与账号管理边界

不存在公开注册 API；POST /api/user 是受保护的超管创号，不能当作注册接口。创号、改密、强制下线、角色、用户软删除和审计查询的方法与授权见总目录；完整逐字段文档待按该模块补齐。

普通退出是本地清理，没有服务端 logout 端点。改密/强制下线通过会话版本撤销此前 token；权限不足与 token 失效不能混成同一种错误。

## 4. 联调复核清单

用户名/邮箱分别登录；多余字段 400；错误账号/密码统一 401；刷新恢复；退出时旧异步响应不恢复身份；改密后旧 token 失效；角色调整后下一请求更新；限流与服务故障分别提示。已有证据和缺口见 [源码验证导读](../05_实现与验证/01_模块源码与验收导读.md#f01)。
