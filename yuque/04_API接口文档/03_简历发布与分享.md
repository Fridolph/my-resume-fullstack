# F04 简历发布与分享接口

日期：2026-11-03。基线：`dev@9367c32`。以下为当前源码整理的 Markdown 接口说明；示例均为合成数据，未在本轮发送请求。通用包装和全量路由见 [API 总目录](00_接口目录与交付约定.md)，业务语义见 [需求](../01_需求文档/04_简历发布与分享.md)。

## 1. 发布、默认与公开读取

| 方法与路径 | 输入 | data / 失败 |
| --- | --- | --- |
| PATCH /api/resume/:id/publish | published:boolean 必填 | id/publishedAt；写入需本人编辑资格 |
| PATCH /api/resume/:id/default | 无业务 body | { id }；未发布为 400 / Resume.Publish:required |
| GET /api/resume/public | 匿名，无 body | ResumeDraftResponse；无可读默认 404 |
| GET /api/resume/public/:id | 匿名，无 body | 指定已发布简历；不可读 404 |

发布请求必须是真布尔，字符串 false 不合法：

```json
{ "published": false }
```

来源：[publish schema](../../apps/server/src/resume/dto/resume-publish.schema.ts)、[ResumeService](../../apps/server/src/resume/resume.service.ts)。取消发布、清默认、撤销旧链接与审计在事务内处理；重新发布不复活已撤销链接。发布没有建立快照，读取仍返回当前文档。

默认最多一份的并发强保证、匿名首页的多作者选择仍有实现缺口，见后端设计，不能凭接口成功断言全局唯一。普通 PATCH/GET 成功 HTTP 200。

## 2. POST /api/resume/:id/shares 创建分享

Bearer，当前实现要求本人且已发布；不要未经核对就为此接口套用正文编辑资格。成功 HTTP 201，data 为 ShareLinkSummary，实际返回字段见 [ShareService](../../apps/server/src/share/share.service.ts) 的 toSummary。token 用于页面 /share/:token，不返回旧路径 /s/。

ShareLinkSummary 包含：id/token、expiresAt/createdAt（时间字符串）、revokedAt（时间字符串或 null）、revokedReason/label/note（字符串或 null）、aiQuota（整数或 null）、aiUsed（整数）、allowPdf（boolean）。管理列表和详情另用共享的 ShareLinkListItem/ShareLinkDetail，不能把元信息 PATCH 响应当作完整列表行。

| 字段 | 必填 | 范围 / 缺省 |
| --- | --- | --- |
| expiresIn | 是 | today/3d/7d/30d/custom；UI 默认 3d，服务端 schema 不缺省 |
| customDays | custom 时必填 | 整数 1～90 |
| aiQuota | 否，可 null | 整数 1～200；缺省/null 不开放，AI 本体及扣减未完成 |
| allowPdf | 否 | boolean，服务端缺省 true |
| label | 否 | trim 后最多 64 字符 |
| note | 否 | trim 后最多 255 字符 |

```json
{
  "expiresIn": "custom",
  "customDays": 7,
  "aiQuota": null,
  "allowPdf": true,
  "label": "面试演示",
  "note": "合成数据"
}
```

来源：[shareCreateSchema](../../apps/server/src/share/dto/share-create.schema.ts)。today 到 UTC 当日 23:59:59.999；其他按服务端当前时间加天数。非法 400，非本人/不可用 404，未发布 400 / Resume.Publish:required。每次请求创建独立链接，超时先核对本人列表，不盲目重复建链。

## 3. GET /api/share/:token 访客读取

匿名，token 为访问凭证，无 body；成功 HTTP 200，data 为 { draft: ResumeDraftResponse }。token 形状见 [schema](../../apps/server/src/share/dto/share-token.schema.ts)。

| HTTP | errorCode | 含义 |
| --- | --- | --- |
| 400 | Common.Validation:failed | token 形状非法 |
| 404 | Share.Link:notFound | 不存在 |
| 404 | Share.Link:expired | 已过期 |
| 404 | Share.Link:revoked | 已撤销 |
| 404 | Share.Link:unpublished | 因发布状态等不可读，按 Service 判定 |
| 429 | Share.Link:rateLimited | 限流 |

当前读取限流为每 60 秒 60 次；访客 IP/UA 等由 Controller 取请求信息，不接受客户端当作可信数据提交。读取成功尽力记录浏览事件，记录失败不阻断主链路。

## 4. POST /api/share/:token/pdf 访客下载

匿名，无业务 body，也不要求 documentHash。除链接可读外还需 allowPdf；禁止时 403 / Share.Link:pdfForbidden。当前每 60 秒 20 次；成功 HTTP 200、Content-Type application/pdf、no-store，失败仍为 JSON。PDF 成功渲染后记录下载事件。

链接授权不封锁 /resume/:id 对应的公开路径；不能将“该 token 禁止 PDF”解释为撤销所有公开来源。

## 5. 分享管理

Bearer，本人归属。响应类型见 [share.ts](../../packages/common/src/share.ts)；query 见 [shareListQuerySchema](../../apps/server/src/share/dto/share-list.schema.ts)。

| 方法与路径 | 输入 / data |
| --- | --- |
| GET /api/shares | 分页、status、resumeId；返回 items/total/page/pageSize |
| GET /api/shares/:id | ShareLinkDetail，含统计与近期事件 |
| PATCH /api/shares/:id | 仅 label/note，至少一项，可 null；返回 ShareLinkSummary |
| DELETE /api/shares/:id | 撤销，返回 id/revokedAt |
| DELETE /api/resume/:id/shares/:shareId | 撤销，核对简历与链接归属，返回 id/revokedAt |

管理查询与修改不可访问他人链接。状态由服务端计算，不由客户端自行重排规则；撤销设计为幂等，但不承诺回放请求的时间戳在真并发下完全一致。期限、PDF 权限和 AI 配额不可通过元信息 PATCH 修改，应新建后撤销旧链接。

## 6. 验证边界

重点验证取消发布再发布后旧 token 失效、到期前后、PDF 直调、备注不改变授权、归属隔离与统计故障。历史 DAO-050 有 Owner 实看和机器验证；本轮未执行创建→访问→撤销→PDF 的自动 HTTP 链路。
