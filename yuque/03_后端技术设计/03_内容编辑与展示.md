## 2. 当前方案

- F03-S01～03 通过完整文档保存入口进入共享 Zod 校验，跨字段规则在 schema 中表达。

## 3. 技术取舍

模块实例按稳定 id 关联排序与纸面引用，模块类型用于选择渲染方式；二者不能互换。结构校验可防止非法形状，但不能单独证明所有前端视图正确渲染。

展示保存与正文保存共享文档，使用 JSON CAS 保证不静默覆盖；因此正文 revision 未变也不承诺请求一定成功。后续扩展先评估文档兼容，再决定是否需要表结构变化。
