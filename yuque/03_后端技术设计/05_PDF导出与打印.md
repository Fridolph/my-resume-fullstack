引用需求中的 F05 场景；展开认证授权、状态、持久化、事务与异常。具体 HTTP 字段以 API 文档和其链接的运行时 schema 为准。

## 2. 当前方案

- `ResumePdfConfigService` 管单份配置与 `ResumeWorkspace.pdfConfig` 个人预设；`expectedConfig:null` 表示此前没有保存配置，不能替换为默认对象。
- 通过 CAS 防止过时配置/文档覆盖；正文、网页展示、纸面配置共享文档时分别保留其他写路径的最新值。
- `ResumePdfService` 校验来源和所有权/发布权限，再按服务端文档与受控模板渲染；本人导出摘要覆盖内容和展示，避免 revision 没变但展示已变。
- PDF 流绕过 JSON 成功包装，异常仍走统一 Filter；设置 `no-store`。Chromium 并发、超时和资源清理属于可用性边界。

## 3. 来源与并发边界

作者端 PDF source=draft 校验本人，source=published 校验公开来源，不将 published 误写成只能本人。分享端下载校验 token 与 allowPdf；二者鉴权入口不同。

配置条件比较中的 null 表示“没有已保存配置”，不是默认对象。DAO-049 最终环境记录已补迁移与实际读写；本轮只重建文档，不执行数据库动作。新版本回退应优先保留兼容可空列。
