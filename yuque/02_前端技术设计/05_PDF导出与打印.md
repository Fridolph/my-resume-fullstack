## 1. 场景与职责

引用需求中的 F05 场景；这里只展开页面、交互和请求设计，不重新定义业务规则。范围为当前 Nuxt 4 实现，Next.js 迁移另行设计。

## 2. 当前方案

- 两端 `/resume/:id/pdf` 复用纸面渲染与分页能力；admin `/settings/print-config` 管理本人跨简历预设。
- 状态分清：读取中、已保存基线、本地临时修改、保存中、冲突、下载中、失败。关闭脏面板时明确保存或放弃。
- 临时导出配置只作用本次下载；“保存本份”和“保存个人预设”不能混为一键。
- 下载请求必须兼容二进制成功与 JSON 错误；不能把错误 JSON 下载成 PDF。
- UI 验收覆盖 A4、页码、长段落、缩放、空模块、深色宿主、手机横向阅读与浏览器打印对话框。

## 3. 状态与请求串联

读取文档/配置 → 记录配置基线 → 本地预览 → 选择临时下载或保存配置 → 成功后更新基线。关闭未保存配置时明确放弃或保存。

完整文档摘要覆盖内容与展示；只用正文 revision 无法发现展示变化。分享 PDF 使用 token 端点，不能要求匿名访客构造作者身份或摘要。

## 5. 验证与影响范围

需求页的验收样本为共同基线；机器检查覆盖类型、构建及已有自动化测试，Owner 另验桌面/移动关键路径。历史执行证据见实现导读，本文不宣称已执行。仅样式变更先核对 UI/前端/测试；若改变请求、权限、结构或恢复语义，需同步 API 与后端评估。
