## 1. 业务目标与角色

作者主动公开简历，并用可撤销、有期限的链接向访客分享。作者需要知道哪些访问入口会受发布、取消发布和撤销影响。


## 2. 共享业务场景

| 场景 | 前置与触发 | 结果与不变式 | 失败出口 |
| --- | --- | --- | --- |
| F04-S01 发布/取消发布 | 作者操作本人简历 | 发布后可公开读；取消时同时取消默认、永久撤销有效旧链接 | 无权/不可访问按授权处理 |
| F04-S02 默认与公开读 | 作者选择默认；访客访问首页或指定简历 | 默认必须已发布；公开读仅返回已发布且账号有效的文档 | 未发布或不存在 404 |
| F04-S03 创建分享 | 本人已发布简历；作者选择期限与权限 | 每次新建独立链接，默认 UI 选 3 天，自定义不超过 90 天 | 非法配置 400；未发布拒绝 |
| F04-S04 访问/下载 | 访客持 token | 校验撤销、过期、发布态；下载另查 PDF 权限 | 链接失效 404；PDF 禁止 403；限流 429 |
| F04-S05 管理分享 | 作者筛选本人链接、查看详情、改备注或撤销 | 状态由服务端判定；授权字段变更需新建并撤销旧链接 | 他人链接 404 |

业务边界：当前公开 URL `/resume/:id` 与分享 URL 并存。分享过期保护这条链接，不能承诺简历在所有路径均不可达。当前公开展示的是可变草稿，发布不生成历史快照。

## 3. 业务规则与边界

- 发布允许公开读取，默认展示必须指向已发布简历；本人最多一份默认是业务意图，当前并发实现尚未强保证。
- 当前发布不生成快照：公开读取当前草稿。已发布后修改并保存正文，会改变访客看到的内容。
- 取消发布同时清除默认并永久撤销旧分享；重新发布不恢复这些链接。
- 指定简历公开 URL 与分享 URL 并存。分享过期/撤销只约束该链接，不保证所有公开路径失效。
- 分享可选择期限、PDF 下载权限、备注与 AI 配额。AI 配额字段存在，AI 对话和扣减执行尚未实现。
- 链接备注可修改；期限及访问授权变更采用新建链接并撤销旧链接，不原地延长。
- 浏览与 PDF 下载有统计；采集告知不等于已取得同意。数据保留和自动清理需补运行证据。

## 4. 前端关注与后端保证

| 视角 | 需要兑现的承诺 |
| --- | --- |
| 产品 / UI | 明示公开范围、当前内容可变、取消发布后果、期限与授权、失效原因 |
| 前端 | 发布操作反馈、复制实际链接、SSR 正确失败状态、列表详情同步刷新 |
| 后端 | 公开状态及作者有效性、链接期限与撤销、PDF 权限、取消发布与撤销同事务 |
| 测试 / 运维 | 到期边界、取消再发布、公开路径差异、统计失败隔离、反代与隐私保留 |

## 5. 验收样本（待执行或核对历史证据）

| 场景 | Given / When / Then |
| --- | --- |
| F04-S01 | 取消发布再发布 → 旧分享仍失效，重新创建链接才能分享 |
| F04-S02 | 未发布简历设默认 → 拒绝并引导先发布；公开读取未发布资源 → 不返回内容 |
| F04-S02 | 已发布后保存正文 → 公开页展示最新内容，符合当前可变草稿语义 |
| F04-S03 | 选择自定义超过 90 天 → 拒绝；默认 UI 为 3 天，复制/二维码打开同一链接 |
| F04-S04 | 链接到期或撤销 → 不返回内容；禁止 PDF 的链接直调下载 → 拒绝 |
| F04-S05 | 修改备注 → 不改变授权和期限；作者 A 管理 B 的链接 → 拒绝 |
