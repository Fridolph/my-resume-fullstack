## 1. 业务目标与角色

作者把简历转换为可阅读、可打印的 PDF，保存单份纸面配置或个人跨简历预设；访客按公开来源或分享授权下载。


## 2. 共享业务场景

| 场景 | 用户行为与规则 | 结果与失败出口 |
| --- | --- | --- |
| F05-S01 预览/下载 | 作者看纸面或导出，访客按授权下载 | 模块显隐、顺序、长文本不静默丢失；渲染失败可重试 |
| F05-S02 保存单份配置 | 作者保存某份简历的纸面设置 | 只改变该份配置；基线改变返回 409，不能静默覆盖 |
| F05-S03 保存个人预设 | 作者保存跨简历默认打印设置 | 后续新建继承；已存在简历配置不被批量覆盖 |
| F05-S04 内容一致性 | 作者预览后文档又改变，再请求导出 | documentHash 不一致则拒绝并提示重新预览 |

非目标：保证不同设备字体完全一致、任意 HTML/URL 转 PDF、完整历史发布版本。

## 3. 业务规则与边界

- 网页展示和纸面版式可以不同，但不能静默丢失应输出内容。
- 临时导出配置只影响一次下载；保存本份只影响该简历；个人预设影响后续新建，不批量改变旧简历。
- 配置保存应发现过时基线；已预览内容发生变化后，作者下载应提示重新预览。
- 分享下载按 F04-S04 校验链接与 PDF 权限，不能仅以按钮可见性授权。
- 不保证不同系统字体完全一致，也不提供任意网页地址转换 PDF 的能力。

## 4. 前端关注与后端保证

| 视角 | 需要兑现的承诺 |
| --- | --- |
| 产品 / UI | 区分临时导出、本份保存、个人预设；展示分页、长文本与下载失败 |
| 前端 | 纸面预览、脏状态与冲突恢复；正确区分 PDF 文件和 JSON 错误 |
| 后端 | 校验来源与权限、文档摘要一致、配置并发保护、受控渲染与资源释放 |
| 测试 / 运维 | 长文完整性、权限、冲突、中文字体、Chromium 依赖、超时与并发 |
