- 沉淀候选：`候选观察` —— **"封装组件应设 `inheritAttrs: false` + 显式 `v-bind="$attrs"`，且属性只绑一处"** + **"头尾固定要落在 flex 结构上，而不是指望 CSS sticky"**；另有两条实测教训（见下）。
- 收口备注：本轮踩到两个**"看起来在生效、其实从未生效"**的坑，值得沉淀：
  1. `MyDrawer` 把 `:ui` 绑成了**调用方的覆写**（`ui`）而不是**计算后的映射**（`drawerUi`）→ 尺寸档位、`flex flex-col`、`body: contents` **从未生效**，表现却是"宽度不太对 + 头尾跟着滚"这类**不像 bug 的症状**；
  2. `<template v-if="x" #title>` 这种 **`v-if` 与 slot 缩写同写无效** → 兜底 slot 静默不渲染。
  共同特征：**没有报错、没有警告、界面"看起来还行"**。判定手段只能是把"预期生效的类/属性"在真实 DOM 里查出来（本轮就是靠 `scrollers` / `titleSlots` / `ariaLabelledby` 三个 dump 定位的）。
