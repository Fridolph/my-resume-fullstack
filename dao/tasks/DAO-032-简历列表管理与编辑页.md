## 目标与边界

- 目标：让概览页成为一个**能管理简历**的入口，并提供"进去改内容"的编辑页。
- 范围（本期）：
  - 列表从手写行改为 **`UTable`**（Owner 指定：后续字段会变多、交互会变复杂，表格更好承载）
  - 行内操作：**编辑**（进编辑页）、**删除**（二次确认后软删除）；卡片视图给同样的两个动作
  - 后端 `PATCH /resume/:id`（重命名）、`DELETE /resume/:id`（软删除）
  - 编辑页 `/resume/:id/edit`：改简历名 + 按模块改内容，保存走 `PUT /resume/:id/draft`（条件更新）
  - **表单内「删除某一项」也要二次确认**（Owner 补充要求）：条目常是刚填过的，手滑代价高；
    确认弹窗带防误点倒计时，在共享表单里实现（见「关键设计」），web 的草稿编辑器同步生效
  - 共享表单两处增强（见下）
- 非目标：
  - **查看详情预览**（`/resume/:id`）—— 要用公开站的展示层，而那套组件在 web 的 layer 里，
    按分层约定 admin 不能直接引用。Owner 已定：**先把展示层上提到共享层（独立一轮），再接详情页**。
    本轮因此**不放"查看"图标**（不做一个点了没去处的按钮），卡片/行也不做点击跳转。
  - **自定义模块**（Issue #39）：Owner 已定留给它单独一轮（要动共享契约 + web 展示注册表）。
  - **日期编辑**：契约的 `date` 是判别联合（`custom` 文本 / `structured` 起止 + 至今），
    现有字段类型表达不了；本轮只读展示。评分量尺（`5 | 10 | 100` 枚举）同理不编辑。
  - 详情配置（`display`）、版本历史、发布分享。
- 涉及文件 / 模块：
  - 后端：`apps/server/src/resume/{resume.controller.ts,resume.service.ts}`
  - 契约：`packages/common/src/resume/document.ts`（`renameResumeSchema` / `ResumeDate`）
  - 共享表单：`packages/common/src/ui/form-schema.ts`（新字段类型 `textItems`）、

## 关键设计（决定了实现形态，值得留给后来者）

| 决定 | 理由 |
| --- | --- |
| 编辑页**就地编辑文档对象**（root = 某模块的 `data`），不做"编辑态 ⇄ 契约"双向转换 | 表单只覆盖部分字段。若先转成编辑态模型再从模型重建文档，`hero` / `interests` / `stats` / `gallery` / 评分维度 / `display` 会被静默丢掉 —— **编辑一次等于删一次**。就地编辑让未覆盖字段随对象原样保存 |
| 新增条目的 id 在**提交前统一补齐**（`assignMissingIds`） | 表单的 `blank` 模板是静态对象，克隆出来的 id 若固定就会重复（契约要求文档内 ID 唯一），若为空则提交非法。把"生成 id"收到提交前，字段表不必承担随机性 |
| 提交前自己跑 `resumeDocumentSchema.safeParse` | 与创建页一致：把必然被拒的输入在请求前用人话指出（`describeContractIssues`，两个页面共用） |
| 新增字段类型 `textItems` | 契约里"成果 / 技术栈"是 `[{ id, text }]`，而非 `string[]`；让组件直接产出契约形状，页面不必各写一层包装 |
| 重命名**不要 revision**、删除**不要二次确认之外的参数** | 名字是单字段整体覆盖，不涉及"整段文档被覆盖"的风险；为它加版本号只会让调用方多背一个并发概念。文档保存仍严格要求 `expectedRevision` |
| 「删除某一项」的确认放在**共享表单内部**（`MySchemaForm` + `MyModal`），而不是交给各页面 | 删除按钮就在表单里，让每个调用方各自接一次确认，迟早漏掉一个。放共享层后 admin 编辑页与 web 草稿编辑器**同时**获得保护 |
| 删条目**只确认、不倒计时**；删整份简历**确认 + 3 秒倒计时** | 两者产品语义不同：整份简历的删除不可逆、频率低，值得让人停一下；条目删除是编辑中的高频整理，加等待只会烦人。用同一套"确认"、不同的"重量"，而不是把最强的保护无差别套上 |
| 顺带修 `DeleteConfirm` 的倒计时 | 它原在 `onMounted` 里 `start()`：组件常驻页面时只会跑一次，**第二次打开就没有防误点倒计时**了。改成 `watch(open)`（`immediate` 兼顾 `useOverlay` 的挂载即开场景） |
