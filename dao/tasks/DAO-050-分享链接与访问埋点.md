## 目标

把「分享」从**作者级开关**（`Resume.publishedAt`）升级为**链接级授权**：

1. 每条分享链接有**独立有效期**（默认 3 天，上限 90 天）
2. 可**主动撤销**；简历取消发布时链接失效，且**能分别说明失效原因**
3. 有**权限位**（`allowAi` 预留、`allowPdf`）
4. 记录**访问行为**（浏览 / PDF 下载 / AI 对话 / 外链点击 / 主题切换），admin 可查
5. 受控分享 **`noindex`**；公开主页的收录由 settings 开关控制

## 非目标

- AI 对话本体（只留 `allowAi` 位与事件类型）
- 自定义封面 / 链接密码（百度网盘有，本轮不做）
- 跨天追踪同一访客（与隐私处理冲突，见设计文档 §4 决策 4）

## 为什么值得单独立卡

它需要 **2 张新表 + 迁移 + 公开读路径改造 + 新页面 + 埋点管道**，
且与既有两条约束直接冲突，必须显式取舍：

| 冲突 | 取舍 |
| --- | --- |
| `publishedAt` 是作者级开关，分享是链接级 | 两条路径**都过 `publishedAt`**：链接授权不能绕过"未发布不可读" |
| 埋点是匿名高写入，`audit_logs` 是有 actor 的强一致记录 | **分表**，不混 |
| `noindex` 常被当成访问控制 | 文档里写明它只是对守规矩爬虫的约定，**不是**访问控制 |

## 验收标准（分四轮，见设计文档 §6）

**R1 数据与读写**
1. 建 3 天链接 → 能用 `/s/:token` 读到
2. 超过 90 天被服务端拒绝（不只是 UI 拦）
3. 过期 / 撤销 / 取消发布 / 简历删除 → 各自返回**不同的 errorCode**，失效页分别说明
4. `allowPdf = false` 时 PDF 端点拒绝

**R2 分享入口**
5. 复制链接成功有即时反馈；二维码可扫码打开
6. 有效期四个快捷项 + 自定义，超限被拒
7. 未发布时**不出现**分享入口，改为"先发布"引导

**R3 埋点**
8. 通过引导页确认后才写 `view`（未同意不计入）
9. PDF 下载 / 外链点击 / 主题切换各有对应事件
10. 事件里**不含**简历正文、姓名、手机号、邮箱

**R4 admin**
11. 能按简历 / 状态 / 是否过期筛选分享链接
12. 能看某条链接的事件统计（被看几次、是否下载过 PDF）
13. 能撤销一条链接，撤销后立即不可读

## 已定的两个非显然结论

1. **Toast 是「告知」，不是「同意」**：没有同意门，`view` 在页面加载时即写入，采集是全量的。
   文档与代码注释都必须这么写，不能宣称"已获访客同意"。
2. **完整 IP 是「有意采集的可识别信息」**：仅用于学习与功能展示、不商用；
   保留期 90 天。若转真实业务必须先脱敏或取得明确同意。

## 风险

1. **token 强度与限流**：`/s/:token` 是公开端点，token 必须 ≥16 字符随机串，且必须限流；
   否则等同于开放暴力枚举。
2. **引导页的"同意"在技术上有个坑**：HTTP 请求到达时 IP/UA 已被服务器看到。
   要让它有意义，只能在**加载时不写任何访客信息**，等确认后再 `POST /s/:token/ack`。
   代价：没点同意的访问不计入统计。
3. **`indexable` 是新增列**，且**不能与 `isDefault` 隐式联动** ——
   否则切换默认简历时会静默改变 SEO 状态。
4. **取消发布的语义**：派生失效（重新发布会复活旧链接）vs 物化撤销（永久失效）。
   两者都合理，但必须选一个并写进接口文档。
