## 风格口径修订（2026-10-08 同日）

| 分号             | 无                            | `semi: false`                                                                                                                                                  |

### 验证中发现的真实问题（值得记住）

二次质量门里 **`pnpm build` 首次失败**，报错在 `ResumeSchemaForm.vue`：
模板属性里的**多语句内联表达式**（`item[field.key ?? ''] = $event; emit('change')`）被 oxfmt 按 JS 语句折成多行，
而 Vue 模板属性只允许**单个表达式** → 构建期 `Error parsing JavaScript expression`。

- **`typecheck` 与 `oxlint` 都不报**：它们不校验模板内联表达式的语法；
- 修复：抽成方法调用（`setItemValue(item, key, $event)`）；
- 已沉淀为 `docs/dev/nuxt-naming-and-pitfalls.md` §6（含排查命令）。
