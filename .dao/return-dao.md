# 项目归母记录

> 本文件只记录项目侧的经验与归母建议。它不代表 Dao 母仓已接受任何内容，也不替代 `dao-return-dao` 的成熟度判断。

## 记录规则

每条候选至少写清：触发事件、涉及层级、可复用判断、证据或反例、建议落点、当前结论与下一步。

当前结论只使用：

- `留项目`
- `候选观察`
- `可以归母`
